# Agent Workflows

This directory is reserved for examples that prove ForgeCAD's agentic CAD loop.

Initial examples should cover:

- Inspecting the current model.
- Capturing a multi-view screenshot.
- Exporting STL.
- Debugging a failed model with metadata and checkpoints.
- Iterating on a simple bracket or enclosure.

Examples should be usable from generic MCP clients, not only from VS Code.
